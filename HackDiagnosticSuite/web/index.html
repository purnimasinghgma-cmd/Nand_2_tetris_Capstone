Part C: Keyboard polling and screen

Box.asm polls the keyboard register. While a key is held it writes -1 into screen rows 41 to 60.

Screen output (512 × 256)

Speed: 5000
How the keyboard polling works. Press and hold any key on your physical keyboard. The browser sends the key to Python, which sets the keyboard register at address 24576. The running Box.asm loop reads it, and writes -1 into screen rows 41 to 60. Releasing the key writes 0 and erases the box.
